# GitHub 视频生成项目调研

调研日期：2026 年 10 月 14 日。

目标是为 ai-auto-video 选择“把主题、文案或已有素材制作成短视频”的组件，重点考虑中文、无 GPU、可控素材和程序化调用。本轮阅读了六个原始仓库的 README，并抽查配置、接口代码和许可证；尚未安装、生成样片或测试发布。

## 文件导航

- [项目与方法对比](comparison.md)：六个项目的定位、中文与 GPU 情况、接口、依赖和选型建议。
- [制作成本估算](cost-estimate.md)：30 秒和 60 秒视频的单条费用、月度费用、官方单价与计算假设。
- [样片验证计划](evaluation-plan.md)：统一输入、记录模板、通过条件，以及如何决定是否继续集成。
- [整体实施方案](../../docs/implementation-plan.md)：账号管理、发布、任务恢复等完整产品设计。

## 初步结论

建议先验证 **MoneyPrinterTurbo**，它的文档与接口最贴近当前的中文短视频生产需求。如果内容主要来自已有视频，再验证 **NarratoAI**。**ShortGPT** 可作为 Python 框架备选。详细依据和限制见[项目对比](comparison.md)。

short-video-maker 有清晰的自动化接口，但当前 README 明确限定英文配音；MoneyPrinterV2 偏海外运营；ai-shorts-generator 值得参考素材复用和云端画面生成，但需要补充中文与稳定性验证。

这些是针对本项目的适配判断，不是成片质量或运行速度排名。第一轮不按 Star 数选型，也不根据项目名称推断赚钱能力。

## 这个目录保存什么

本目录保存调研结论和验证计划。后续测试可以在这里补充固定提交版本、配置摘要、样片路径和结果；API 密钥、账号登录文件和大体积成片应放在运行数据目录，避免混入调研文档。

本轮没有拉取第三方仓库或执行其安装脚本。正式试验前固定版本，防止 README、接口和运行依赖在测试期间发生变化。
