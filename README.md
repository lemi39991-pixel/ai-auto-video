# ai-auto-video

面向抖音的 AI 短视频制作与发布工具，计划整合 MoneyPrinterTurbo 和 social-auto-upload，实现选题、脚本、配音、剪辑、预览确认、发布与效果记录。

当前处于方案设计阶段，尚未实现或验证完整工作流。第一版以单账号、无 GPU 部署、确认后发布为目标。
